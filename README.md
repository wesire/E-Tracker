# Economy Tracker (E-Tracker)

A production-ready macroeconomic insights application.

> 🚧 Under construction — full application being built via PR.

## Overview

Economy Tracker gives users actionable macroeconomic insights across countries and regions. It ingests reliable public data from FRED, World Bank, and OECD, normalizes it, calculates derived metrics, and presents clear narrative insights.

## Tech Stack

- **Frontend**: Next.js (TypeScript), Tailwind CSS, shadcn/ui, Recharts
- **Backend**: FastAPI (Python 3.12), SQLAlchemy, Alembic
- **Database**: PostgreSQL
- **Jobs**: APScheduler
- **Cache**: Redis
- **Containers**: Docker + docker-compose

## Quick Start

```bash
docker compose up
```
